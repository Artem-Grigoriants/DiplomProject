### Проведенные улучшения

В ходе работы над проектом были внедрены следующие улучшения для повышения производительности, надежности и функциональности:

1.  **Асинхронные задачи с Celery**: Фоновые и длительные операции (например, отправка email) были перенесены из синхронного выполнения в асинхронные задачи с использованием Celery. Это позволило значительно сократить время отклика API и улучшить пользовательский опыт.

2.  **Автогенерация документации API (DRF-Spectacular)**: Внедрена библиотека `drf-spectacular` для автоматической генерации документации Open API (Swagger UI). Это упрощает тестирование API, его понимание и командную работу над проектом.

3.  **Троттлинг запросов (DRF Throttling)**: Настроен механизм троттлинга для ограничения количества запросов от пользователей. Это защищает сервис от злоупотреблений и DoS-атак, обеспечивая стабильную работу для всех.

4.  **Авторизация через социальные сети**: Добавлена возможность входа в систему с использованием аккаунтов Google и Yandex через библиотеку `Python Social Auth`. Это предоставляет пользователям удобный и быстрый способ аутентификации.

5.  **Улучшенная панель администратора (Django JET Reboot)**: Стандартная админ-панель Django была заменена на `django-jet-reboot`, которая предлагает более современный и функциональный интерфейс для управления данными.

6.  **Обработка изображений (Easy Thumbnails)**: Реализована загрузка аватаров пользователей и изображений товаров с последующим созданием миниатюр (thumbnails) с помощью `easy-thumbnails`. Это оптимизирует загрузку страниц и экономит трафик.

7.  **Мониторинг и перехват ошибок (Rollbar)**: Интегрирован сервис Rollbar для централизованного сбора и анализа ошибок, возникающих в приложении. Это позволяет оперативно реагировать на проблемы и повышать стабильность сервиса.

8.  **Кэширование запросов к БД (Cacheops)**: Внедрена библиотека `django-cacheops` для кэширования запросов к базе данных с использованием Redis. Это значительно ускоряет повторные запросы и снижает нагрузку на базу данных.
